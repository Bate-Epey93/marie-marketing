# I am that Girl! — Le petit guide marketing de Marie

PWA en français pour la stratégie marketing d'un salon de beauté (coiffure, peau, ongles, spa).

- Page **Aujourd'hui** : date, affirmation, une action par section
- Cadres stratégiques, Kit de marque, Réseaux sociaux, Banque d'idées, Visibilité locale, Calendrier de contenu, Commercialisation, Assistante IA, Glossaire
- Fonctionne hors ligne, installable sur téléphone
- Données enregistrées dans le navigateur uniquement

Fichiers : `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`. Aucun build, aucune dépendance.
